# 工作流 01：水样测试（拍照 → 读数 → 出表 → 回写）

> 适用场景：用户发来水样比色管照片，要求读数/测水。
> 详细知识沉淀（色阶、锚点、避坑、业务机理）已内嵌于 `工具/water_toolkit.py`；标准比色卡（锚点权威来源）在仓库根目录 `比色卡/`。本文件是执行手册。

## 一、输入

用户直接发来照片/图片（不另下指令，见 README 工作流索引）。**先按第 0 步判断是否比色管**，是才进入本流程；通常会说明是哪家的塘（如“丁杰秋 1–7 号塘”），或按微信发送顺序对应塘号。

## 二、执行步骤（5 步）

0. **判是否比色管（前置门禁，先过这关）**：收到照片先判断是否水样比色管（带液柱、配色阶/比色卡的试管）。
   - 不是比色管 → 直接返回（原图退回，不按水样流程读数，也不猜它是什么）；
   - 是比色管 → 进入第 1 步正常识别读数。

1. **查方向**：照片不正（管口横置）→ 旋转至管口朝下（工具包 `rotate_tubes_down` 自动处理横图）。
2. **定塘号**：按用户告知或微信发送顺序确定塘号，照片时间戳为凭证；**不确定先问用户，不要猜**。
3. **读数**：**以目视（人眼或多模态模型视觉）直接比对 `比色卡/` 标准卡出数**（方法见第三节）；程序工具仅作辅助筛查与留痕，外拍照上禁止直接采信程序自动读数。
4. **输出**：竖线表格，微信里能对齐，**单一数值、不写“约”**：

   | 塘号 | 时间 | pH | 氨氮 | 亚硝酸盐 |
   |---|---|---|---|---|
   | 1号塘 | 09:02 | 6.9 | 0.3 | 0.12 |

5. **⚠️ 规则（自动执行，不问用户）**：
   - 亚硝酸盐 ≥ 0.3，或接近（0.28）→ 标 ⚠️，备注“亚盐接近/超量程”；
   - 氨氮 ≥ 5（高量程）→ 标 ⚠️，备注“氨氮≥5⚠️”；
   - 亚盐超量程时给估值并注明“超量程估值，鱼易浮头”；
   - 其余一律不标。

## 三、读数方法（目视出数 + 程序辅助筛查）

### 辅助：工具包程序筛查（有 Python 环境；仅辅助筛查，不出数）

```python
# 在本资料包根目录下执行
exec(open("工具/water_toolkit.py", encoding="utf-8").read())

# 辅助筛查（不框选，脚本自己定位液柱；读数仍以目视为准）
r, meta = auto_read_photo("照片存档/水样照片_20261013_001.jpg")
# r: {项目: {"value","warn","hsv","n","note"}}；meta: 每根管的 cx/detected/transparent/box 供人工复核

# 复核：自动结果可疑时，按 meta 的 box 或自行框选三管液柱中部，手动重读
r = read_photo("照片存档/水样照片_20261013_001.jpg",
               {"pH": (x1,y1,x2,y2), "氨氮": (...), "亚盐": (...)})
```

- `auto_read_photo` 全自动检测（2026-10-13 上线）：竖直边缘投影定位液柱 → 双判据验证 → 等宽等距补齐 → 采样读数，全程零框选。**⚠️ 定位：仅辅助筛查。2026-10-13 丁力强 4 塘外拍实战证明其在户外手持侧拍+水面蓝天背景下系统性失灵（检管失败/背景污染/透明误判），其结果不得作为读数依据、不得直接对外汇报。**
- 工具包已内置：白平衡校正、色调族采样、锚点换算表、亚盐超量程外推、⚠️ 规则。
- **透明规则（2026-10-13 追加，2026-10-27 修订：氨氮近透明读 0，用户规则）**：比色管液体与背景很相似 → **看成透明**，即水质很好、检测不出来，直接读近零（氨氮 0、亚盐 0.005），不强行匹配锚点。工具内判定：饱和度 < 0.22，或与背景色几乎一致（ΔS<0.05 且 ΔH<30°）→ 记 transparent。
- 复核要点：meta 里 `detected=False` 的管为按等宽等距推算的位置（液柱近无色，靠玻璃轮廓 + 周期推定）；`transparent=True` 的管读近零（氨氮 0、亚盐 0.005）。两者都要人工注目确认。11:30 西坡村实战图验证：管位误差 ≤6px，全自动读数与手动基准完全一致。
- 锚点表源自 `比色卡/` 5 张单盘标准卡实测标定（2026-10-13，统一白平衡下逐扇区取色），与卡面印刷值一一对应。
- 氨氮爆表（>1.5）改用高量程卡读数，键名写 `"氨氮(高量程)"`。
- 俯拍视角传 `view="top"`（pH 会偏深 0.1–0.2，工具包自动备注）。
- 依赖：Pillow、numpy、matplotlib。缺则先 `pip install pillow numpy matplotlib`。

### 出数方法：目视比对标准卡（唯一出数依据，2026-10-13 起）

- **本方法是唯一出数依据（2026-10-13 定性：纯程序读数在外拍场景根本读不准）**：逐管目视颜色，与 `比色卡/` 标准卡对应扇区比对定档。
- 管序约定：**左 pH（绿）、中氨氮（黄）、右亚盐（粉）**，偶有不同以实际颜色为准。
- 色阶（印刷值，与 `比色卡/` 标准卡一一对应，人眼读数时直接对照标准卡）：
  - pH 低量程：6.50 / 6.80 / 7.00 / 7.20 / 7.40 / 7.60（黄→绿）
  - pH 高量程：7.80 / 8.00 / 8.20 / 8.60 / 9.00 / 9.50（绿→蓝）
  - 氨氮低量程：0.20 / 0.40 / 0.60 / 0.90 / 1.20 / 1.50（黄→橙→红棕，越深越高）
  - 氨氮高量程：2 / 3 / 5 / 8 / 15
  - 亚硝酸盐：0.005 / 0.05 / 0.10 / 0.15 / 0.20 / 0.25 / 0.30（浅粉→深品红）
- **近无色一律按近零读，不上探（氨氮近透明读 0，亚盐近无色读 0.005）**。
- 工具读数与人眼矛盾时，**以人眼颜色为地面真值**，并在备注写明“人眼锚定”。

## 四、避坑规则（历史训练沉淀，务必遵守）

1. 红色液体在蓝天/水面背景前会被拍偏紫 → 先做白平衡校正再读；亚盐像素色相落在 0.80–0.88 属白平衡过冲偏紫，**按明度定档，不按色相**。
2. 俯拍（管立卡上）读数偏深：pH 偏高约 0.1–0.2，氨氮/亚盐饱和度偏高 → 优先按手持侧视读。
3. 像素级一致的重复图判为同一塘，不重复记录。
4. 像素与人眼矛盾时以人眼为准。
5. **比色管液体与背景很相似 → 看成透明**（2026-10-13 用户规则）：近无色的氨氮/亚盐管是"水质很好、检测不出来"，按近零读（氨氮 0、亚盐 0.005），不要硬套锚点往上猜。背景的水面波纹会让背景检测大面积误报，近无色管的液体与背景 HSV 统计几乎一致——颜色检测对这类管无效，定位只能靠玻璃轮廓 + 等宽等距推算，工具已内置。
6. **外拍照禁止直接采信程序自动读数**（2026-10-13 实战实锤，用户定性"纯程序判断根本读不准"）：户外手持侧拍+水面/蓝天背景下程序读数系统性失真——① `auto_read_photo` 检管失灵（4 张外拍照检出的"管宽"767/120/228/354，实为把背景/水印当管）；② 大框 pH 采样被天空污染（2号塘误读 9.00，实为 7.4，框内 51.3% 为低饱和高亮天空像素）；③ 透明判定误杀淡粉（2号塘亚盐误读 0.005，人眼见清晰淡粉，实为 0.05–0.10）。程序结果仅作筛查线索，出数必须目视比对标准卡；矛盾时以人眼/地面真值为准。

## 五、拍照规范（用户侧参考，照片有问题时提醒用户）

- 首选**手持侧视**：液柱侧面颜色均匀，与锚点表一致；
- 背景用白色（白桶/白纸），避免红管正对蓝天；
- 距离 20–30 cm，手机正对液柱中部；塘号写纸条入镜或按发送顺序编号。

## 六、记录回写（每次测水后必做）

把结果**追加**到 `数据/水质检测记录.csv`（只追加、不覆盖），列结构固定：

```
用户,塘号,位置,日期,时间,pH,氨氮,亚盐,备注
丁杰秋,1号塘,锦山镇039乡道,10.05,09:02,6.9,0.3,0.12,
```

- 日期格式 `M.DD`，时间 `HH:MM`；⚠️ 写在备注列（如 `亚盐接近0.3⚠️`、`氨氮高量程;氨氮≥5⚠️`）。
- 同时把要点更新进客户档案类文件（见 `工作流/02_客户名单管理工作流.md`）。
- 新照片存档到 `照片存档/`，命名 `水样照片_YYYYMMDD_序号.jpg`。

## 七、服务建议输出（可选，用户需要时）

- 亚盐 ≥0.3 / 氨氮 ≥5 的塘口：建议 2 天内复测，并给调水建议（减料、增氧机凌晨开、换水 10–20%、沸石粉/食盐/过硫酸氢钾，详见完整档案第七节）。
- 临界塘口 = 回访由头，2 天后主动约复测。

## 八、算法推理过程（低级会话必读；改工具前必读）

> 目的：让没有强推理能力的会话也能安全使用本流程。核心一句话：**读数靠目视比对标准卡，程序只作筛查线索**。推理链写在这里，是为了防止低级会话"好心改错"。

### 8.1 auto_read_photo 的五步推理链

1. **竖直边缘投影找管**：手持侧视的比色管是"带竖直玻璃边的柱子"，V 通道 x 方向梯度在管左右边缘成峰；取 y 上部 75% 做列投影（液柱在画面上部，底部常有水印干扰），过阈（mean+2std）的峰即候选管边。
2. **双判据验证候选峰对**（两个判据各防一类翻车，是"或"的关系）：
   - 颜色判据（带心饱和度 > 背景+0.15）：防"背景杂物被当成管"。注意采样窗两端各缩 12px——贴邻管的折射暗边伸进窗内会冒充有色（翻车过）；
   - 横线判据（带区内有横跨整带的强水平线，覆盖度 >0.4）：防"近无色管被漏掉"。液面/管底是玻璃管结构特征；波纹背景也有横线，所以要"横跨整个管带"且只取上部 75%（底部水印区全是线，翻车过）。
3. **受控共享峰合并**：一根有色管被内部竖直纹路劈成左右两半（出现两个峰）时，仅当两半都"有色"才合并还原。**不能无差别合并**——曾把三根贴邻管并成一根巨管（还混入手指，翻车过）。
4. **等宽等距推算补齐**：同批比色管等宽、并排手持近似等距。用检出管宽度 W 与间距 P（多带检出取中位间距；单带取 1.5W 先验，偏差较大）推算近无色邻管位置。11:30 西坡村实战图：检出中管后推算邻管 742/1094 vs 真值 740/1100，误差 ≤6px。
5. **液柱段共用**：并排管的液柱 y 对齐，取检出带内饱和度显著高于背景（>背景+0.08）的最长连续行段，所有管共用，避免每根管各自采样采到干区。

### 8.2 为什么近无色管不能靠颜色检测（背景的欺骗性）

- 水面波纹让背景区的"差异像素"（(s_diff>0.08)|(v_diff>0.10)）大面积成立，**背景检测本身不可靠**；
- 实测近无色管的液体与背景 HSV 统计几乎完全一致（右管 V0.776/S0.170 vs 纯背景 V0.765/S0.179）——**颜色信息为零**；
- 所以近无色管只能靠"玻璃轮廓检出 + 周期推算"定位，读数按透明规则走近零。这不是将就，是物理上正确的结论：没有显色反应 = 水质很好、检测不出来。

### 8.3 透明判定（用户规则 2026-10-13，已写死在代码里）

饱和度 < 0.22，或与背景几乎一致（ΔS<0.05 且 ΔH<30°）→ 判透明 → 读近零（氨氮 0、亚盐 0.005），**不强行匹配锚点**。代码路径：`sample_liquid` 返回 `hsv=None, transparent=True`，`hsv_to_value` 收到 None 走 `NO_COLOR` 低档。

### 8.4 历史踩坑与根因（防止低级会话"改回去"）

| 现象 | 根因 | 现状 |
|---|---|---|
| 旧工具 pH 8.6 欠读为 7.4 | 色调族窗口(HF)容不下蓝绿色 H≈169° | HF 已放宽至 0.62；11:30 西坡村实测 8.60，与地面真值一致 |
| 三根管被并成一根巨管 | 无差别共享峰合并 | 仅两半都有色才合并 |
| 左管折射暗边被当成独立管 | 采样框贴到邻管暗边 | 框两端各缩 12px |
| 水平线峰落在底部水印区 | gy 投影未限 y 范围 | 限上部 75% 且线覆盖度 >0.4 |
| 亚盐爆表样本漏读且不标⚠️ | 亚盐明度非单调（0.20 档反而最暗） | 外推逻辑已修，爆表必出⚠️估值 |
| 手动框选框偏（采到背景） | 缩略图目测 y 坐标偏差 | 已由程序逐列/逐行扫描定位取代（detect_tubes） |
| 外拍照纯程序读数系统性失真（2026-10-13 丁力强 4 塘实战） | 蓝天低饱和高亮像素污染采样框；透明阈值 S<0.22 误杀淡粉管；detect_tubes 把水面/水印当管 | 工作流改为"目视比对标准卡为唯一出数方法"，程序仅辅助筛查；详见避坑#6 |

### 8.5 低级会话使用守则（红线，违反即出错）

1. **不要"优化"阈值**：0.22（透明）、0.15（带心饱和差）、12px（缩边）、0.4（线覆盖度）、1.5W（单带间距先验）全部是踩坑换来的；改任何一个之前，先跑 `verify_anchors()`（应 30/30）并回归 8.4 表全部场景。
2. **meta 里 `detected=False` 或 `transparent=True` 的管**：位置是等宽等距推算的、读数是低档——必须在给人看的回复里注明"该管为推算/透明低档，请人工确认"，不得当成精确检出直接汇报。
3. **外拍照读数以目视（人眼/多模态模型视觉）比对标准卡为唯一出数依据**；程序自动读数仅作筛查线索，与人眼矛盾时以人眼为地面真值，备注写"人眼锚定"——2026-10-13 起纯程序读数不得直接对外汇报。
4. **不是比色管的图不要硬读**：`detect_tubes` 检不出管（返回空/极少带）时，按第 0 步原图退回，不猜是什么。
5. 俯拍 `view="top"` 会让 pH 偏深 0.1–0.2，工具会自动备注，**不要手工"修正"它**——那是物理现象不是误差。
6. 本文件的推理链与 `工具/water_toolkit.py` docstring 互为指针；改工具行为时同步更新两处。
