## 一、体系定位（重要边界）

YOLO **不直接吐读数**。本目录是两段式管线的第一段：

```
照片 ──► ① YOLOv8 检测 tube ──► 每根管的紧致边框（外拍鲁棒，替代 detect_tubes）
                │
                ▼
        ② infer.py 框内定位液柱段 + 取代表色（复用 water_toolkit 的白平衡/色调族口径）
                │
                ▼
        ③ 按代表色与三族锚点距离定指标（不依赖管序）→ hsv_to_value 换算 + need_warn ⚠️
                │
                ▼
        读数初判（辅助）──► 人眼/地面真值仲裁（红线，见 工作流/01 避坑#6）
```

- 第二段"色档定档"的升级路线（可选）：用 `比色卡/` 5 张标准卡程序化增广生成海量
  训练对，训一个 30 档色档分类器替代锚点最近邻——标准卡是权威源，数据零成本。
- `工具/water_toolkit.py` 的色阶表/⚠️规则/亚盐外推/避坑等业务资产**全部保留复用**，
  本体系只替换"检管+采样"两个失灵的环节。

## 四、端到端验证证据（未微调预训练权重，2026-10-13）

推理链全跑通后的逐塘比对（CSV 记值 = 当日人眼/地面真值）：

| 照片（塘号） | 管线输出 | CSV 真值 | 判定 |
|---|---|---|---|
| rot_1（4号塘） | pH 7.20 / 氨氮 0.20 / 亚盐 0.005 | 7.2 / 0.2 / 0.005 | **3/3 全对** |
| rot_3（1号塘） | pH 8.60 ✓ / 亚盐 0.005 ✓ / 氨氮漏检 | 8.6 / 0.2 / 0.005 | 2/3 |
| rot_0（5号塘） | 氨氮 0.20 ✓ / 亚盐 0.005 ✓ / pH 漏检 | 7.4 / 0.2 / 0.005 | 2/3 |
| rot_2（2号塘） | 氨氮 0.40 ✗ / 亚盐 0.005 ✗ / pH 漏检 | 7.4 / 0.2 / 0.10 | 0/3 |

**验证中抓出并已修复的两个 bug（均已落库 infer.py）：**

1. **跨画幅误检框挤乱管序推定**：rot_1 预训练权重把画面上部背景误检成
   横跨 98% 画宽的大框（conf 0.73），使中管被推到 idx=2 推定为亚盐、随后被真亚盐管
   覆盖，氨氮整项丢失。→ 新增 `plausible_box`（宽>70% 画宽或面积>45% 画幅判误检剔除），
   修复后 rot_1 三管全恢复。
2. **近无色管指标探测被背景污染**：近无色管框内混入蓝天像素（H≈0.556 落入 pH 色调族窗
   0.08–0.62），指标误判 pH。→ `probe_color` 增加 bg 排除（ΔS<0.05 & ΔH<30° 判背景）。
   修复后近无色管正确走"按管序位置推定指标"路径。

**残余已知问题（均有明确解法，留待微调阶段）：**

- **漏检**（4 张共漏 3 管）：集中在绿背景前的绿管、近无色管；预训练权重对"比色管"类别
  本身不熟，微调 50–100 张覆盖到位的标注照即可解决（conf 0.25 下 rot_2/rot_3 检出
  conf 仅 0.29–0.53）。
- **绿区撞色**（rot_2）：pH 7.x 与氨氮 0.4 试纸均为绿色，代表色落在两族锚点之间，
  交叉比距离时误判氨氮 0.40。微调后可用"管色分类器 + 位置先验"双证据定指标。
- **淡粉亚盐系统性低估**（rot_2）：亚盐 0.10 淡粉经白平衡后实测 H≈0.63/S≈0.15，
  与标准卡锚点（H≈0.92 品红）色相差距大且饱和度低于 0.005 锚点，`sample_liquid`
  透明判定（S_TRANSPARENT=0.22）误判透明读 0.005。**这是危险的低估方向**，
  佐证红线"外拍照不得直接汇报、以人眼为准"；解法同绿区撞色（色档分类器替代锚点）。

→ 学习门槛不高，**50–100 张覆盖到位的标注照即可产出可用 v1**；
漏检集中在"绿背景前的绿管"与"近无色管"，标注时按 `data/标注规范.md` 的覆盖矩阵加权。

## 四·补、训练冒烟测试（2026-10-13，13 张量级）

数据集 v0.1 入库后跑了全链冒烟（`train.py` → `data.yaml` → 权重 → `infer.py` 回归）：

- **流程全通**：100 epochs CPU 约 4 分钟；从非仓库根目录启动也正常（train.py 绝对路径兜底生效）；
- **val 指标**（3 张 / 9 框）：mAP50 0.62、mAP50-95 0.36、R 0.44、P 0.96——找到的管
  精度高，但漏检仍近半；
- **回归 4 塘**：rot_1（train 内）3/3、rot_3（val）2/3、rot_0 2/3、rot_2 仍 0/3
  （绿区撞色 + 淡粉误透明 + 中管漏检三个老问题一个没解决）；
- **10 张 → 13 张重跑对比**：指标与回归结果几乎无变化，说明剩余错误不是调参能救的，
  **数据规模是硬瓶颈**（val R 0.44 = 未见过管的漏检率）；
- **结论**：冒烟权重仅证明链路可用，**不作为生产权重入库**；预训练权重
  `weights/yolov8n.pt`（hf-mirror 源，AGPL-3.0）作为 infer.py 的降级方案随库分发。
  生产 v1 必须等覆盖矩阵补齐（见第五节待补项）。
