# 标注规范（比色管检测，v1 检测框）

> 目的：给 YOLOv8 检测模型提供口径一致的标注。v1 只标**检测框**（单类 `tube`），
> 液柱分割/颜色定档交给 infer.py 内的液柱段定位 + water_toolkit 换算，不额外标注。
> 标注质量直接决定外拍检管效果——这是今天（10.13）实锤的最大痛点。

## 一、框怎么画

1. **一根管一个框**，框住整根比色管的可见部分（管口到管底），贴边不留大量背景；
2. **近无色/透明管也要标**——液体与背景融为一体的管恰恰是最容易漏检的，训练集必须覆盖；
3. **被手指/管壁遮挡的管**照标（框到可见部分），YOLO 学的就是部分可见的目标；
4. 三根管都要标齐；一张图只有部分管入镜时，标出入镜的即可。

## 二、文件与命名

```
模型/dataset/
├── images/{train,val}/照片.jpg      # 摆正后的竖图优先（管口朝下）；横图先转正
└── labels/{train,val}/照片.txt      # 与照片同名，YOLO 格式:
                                     # 0 <x_center> <y_center> <w> <h>   （全部归一化 0–1）
```

- train/val 按 **8:2** 左右划分，且**同一基地/同一批的照片不要跨集拆**（同批照片背景雷同，跨拆会虚高指标）；
- 照片命名建议带日期地点：`20260821_冯坡士宅村_1012.jpg`。

## 三、覆盖矩阵（尽量每格都有几张）

| 维度 | 要覆盖的情形 |
|---|---|
| 管色 | 绿(pH各档) / 黄(氨氮各档) / **深品红(亚盐高档)** / 近无色(三指标都有) |
| 背景 | 蓝天水面 / 草地 / 室内白墙 / 深色塘基 |
| 视角 | 手持侧视为主，少量俯拍（俯拍标 view=top 的图单独放 val 观察） |
| 光照 | 正午强光 / 阴天 / 傍晚 |
| 管序 | 除"左pH中氨氮右亚盐"外，**刻意收几张管序不同的**（ infer.py 按颜色定指标，正好吃这类样本） |

## 四、质检（入库前自查）

- [ ] 每张图的框数与图中管数一致，无漏标（尤其近无色管）；
- [ ] 框紧贴管体，框内天空/水面像素占比应很低（理想 <15%）；
- [ ] 无跨集同批拆分；
- [ ] 类名统一 `0`（单类）。

## 五、参考基准

- 2026-10-13 实测：未微调的 COCO 预训练权重在 rot_1（4号塘）即 3/3 全检（conf 0.74–0.90），
  说明目标外观学习门槛不高；漏检集中在**绿草地前的绿色管**与**近无色管**——标注时这两类要加权。
