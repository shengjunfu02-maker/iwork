# 包产模型（打样 → 用料 / 售卖预估）

> 来源：2026-10-31 用户提供的《打样预计使用包数预估 / 干塘预计》测算表与《规格—累计包产》表。
> 用途：走访 / 服务客户时，依据塘口与打样数据，估算阶段用料包数、干塘累计包产与推荐售卖规格，辅助通威料转化沟通。
> 维护：表值以原表为准；公式为本库还原口径。

## 一、适用场景
- **打样阶段**：已知「塘口面积、放苗重量、放苗规格、打样重量、打样尾数」，估算本阶段用料包数（推荐包数 ±10）。
- **干塘阶段**：已知计划售卖规格，查「累计包产」估算全程累计用料与推荐售卖重量（±20 / ±1000 斤）。
- **边界**：仅作估算与沟通辅助，最终以实际投喂与出鱼核算为准。

## 二、输入字段（黄底项，仅需填写这些）

| 字段 | 含义 | 单位 |
|---|---|---|
| 塘口面积 | 塘口投料面积 | 亩 |
| 放苗重量 | 放苗总重量 | 斤 |
| 放苗规格 | 放苗密度 | 尾/斤 |
| 打样重量 | 本次打样总重 | 斤 |
| 打样尾数 | 本次打样尾数 | 尾 |

## 三、自动计算链（公式口径）

- 放苗尾数 = 放苗重量 × 放苗规格
- 打样规格(斤/尾) = 打样重量 ÷ 打样尾数
- 阶段增重(斤) = 打样规格 × 放苗尾数 − 放苗重量
- 亩密度(尾/亩) = 放苗尾数 ÷ 塘口面积（原表样本口径待核：面积12 推算约 4720，原表记 3594）
- 推荐使用包数(±10) = 阶段增重 ÷ 对应包产（打样规格查表A）
- 干塘推荐使用包数(±20) = 累计用量 ÷ 累计包产（售卖规格查表B）

## 五、表B：售卖规格 → 累计包产

| 规格 | 累计包产 |
|---|---|
| 1两 | 90 |
| 1两-2两 | 80 |
| 1两-5两 | 65 |
| 1两-8两 | 55 |
| 1两-1斤 | 50 |
| 1两-1.2斤 | 47 |

> 累计包产：自放苗（1两）累计到该规格所需的「斤鱼 / 包料」；规格越大，累计包产越低。

## 六、示例（原表样本）

输入：塘口面积 12、放苗重量 1888、放苗规格 30、打样重量 6.5、打样尾数 8

- 放苗尾数 = 1888 × 30 = 56640
- 打样规格 = 6.5 ÷ 8 = 0.8125 ≈ 0.81
- 阶段增重 = 0.8125 × 56640 − 1888 = 44132
- 推荐包数(打样) = 44132 ÷ 对应包产

> 样本原表记「推荐使用包数 833（±10包）」。反推包产约 53（对应 0.7–0.8 档），而打样规格 0.81 按表A落在 0.8–0.9 档（49），原表内部口径略有出入——录入以原表数值为准，取档规则待确认后统一。

## 七、限制与备注

- 凡放苗为 30000 / 40000 / 60000 或雷同数据过多者，一概不适用 / 需人工判断。
- 只需填写黄色选项，即可输出售卖规格、售卖重量（原表备注）。
- 估算值带浮动区间（±10 / ±20 / ±1000 斤），对外沟通须注明浮动。
- 本模型为通威料转化测算辅助，不替代实际投喂与出鱼核算。
